Para ativar os botões de compra, abra este arquivo: client/public/product-config.js

Preencha o campo hotmartUrl com a URL pública da página de oferta na Hotmart, mantendo as aspas. Exemplo:
window.PRODUCT_CONFIG = { hotmartUrl: "https://pay.hotmart.com/SEU-CODIGO" };

Os depoimentos continuam como espaços reservados até receber relatos reais autorizados. O selo presente no site é editorial, não uma garantia.
